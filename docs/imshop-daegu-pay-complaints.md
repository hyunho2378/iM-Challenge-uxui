## 조사 방법 및 확인 사항

- **1~5번**: 사용자가 제공한 요약과 일치하는 원본 기사를 직접 검색·대조해 URL을 확인했습니다. 2번은 원 매체 "시니어매일"이 2024년 말 폐간 후 "OMATE 시니어"로 재창간되어 과거 기사가 새 도메인(omate.kr)에 보존되어 있는 것을 확인했습니다.
- **6번(Google Play)**: `iM샵(#) - 지역사랑상품권 대구로페이 포항사랑카드` 앱(3.3천 개 리뷰, 평점 3.6)의 리뷰 영역을 반복 스크롤하여 약 150개 이상의 리뷰를 확인했습니다. 별점 1~2점 위주로 카드등록/계좌연결/충전/오류코드/화면 UI 관련 불만을 추출했습니다.
- **7번(Apple App Store)**: 앱 ID `1479028844`(iM샵(#), 813개 평가, 평점 4.0)의 리뷰 미리보기를 확인했습니다. Apple 앱스토어 웹은 전체 리뷰 목록을 페이지네이션 없이 일부만 노출하는 구조라(공개 리뷰 API도 이 앱은 빈 응답), 확보 가능한 리뷰 전량을 확인한 결과입니다. 추가 리뷰가 더 있을 가능성은 배제할 수 없습니다.
- **8번(웹/커뮤니티)**: "iM샵 불편", "대구로페이 충전 안됨", "대구로페이 어렵다", "부모님 대구로페이" 등의 키워드로 검색해 네이버 블로그, 디시인사이드, 매일신문 후속 기사를 확인했습니다. 클리앙·네이버 카페에서는 이 주제로 직접 작성된 글을 찾지 못했습니다(못 찾음).

## 못 찾은 것

- 클리앙, 네이버 카페(대구 지역 맘카페 등)에서 "iM샵"/"대구로페이" 관련 실사용자 불편 게시글은 검색 결과에서 확인되지 않았습니다. 없다고 단정하기보다는, 검색 키워드로는 노출되지 않았다는 점을 밝혀둡니다.
- 디시인사이드 글(22번)은 정확한 작성일이 페이지에 표시되지 않아 "작성일 미상"으로 표기했습니다.
