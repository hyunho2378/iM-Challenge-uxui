# 실서비스 전환 시 확장 방향 (발표 자료용 메모)

06차 지시서 7번. 코드로 만들지 않고 메모만 남긴다.

## 앱 안 켜도 잔액 보이는 위젯

강릉페이 프로젝트에서 다뤘던 기능이다. 이번 프로토타입 스택(웹, Vite + React, 브라우저에서만 동작)으로는 구현할 수 없다.

**이유**: 홈 화면 위젯은 iOS(WidgetKit)와 Android(App Widgets)가 각각 제공하는 네이티브 OS API 영역이다. 브라우저 안에서 돌아가는 웹앱은 홈 화면에 자기 UI를 그릴 권한이 없다. PWA로 만들어도 마찬가지다 — 위젯은 브라우저 샌드박스 바깥의 기능이라 프레임워크 선택과 무관하게 근본적으로 막혀 있다.

**실서비스 전환 시 확장 방향**:
1. React Native 또는 Flutter로 앱 셸을 다시 만들거나, 지금의 웹뷰를 네이티브 앱으로 감싼다.
2. iOS는 WidgetKit(SwiftUI 위젯 익스텐션), Android는 App Widgets(Glance 또는 RemoteViews)로 위젯 자체를 별도 구현한다.
3. 위젯이 보여줄 데이터(잔액, 이번 달 할인충전 사용액)만 딱 필요한 만큼 별도의 가벼운 조회 API로 노출한다 — 지금 서버의 세션 기록용 API와는 분리해서, 위젯이 자주 폴링해도 부담 없는 읽기 전용 엔드포인트로 설계한다.
4. 잔액처럼 민감한 정보를 잠금화면 위젯에 그대로 노출할지는 정책 결정이 필요하다 — 마스킹(예: "충전 필요" 상태만 표시) 옵션도 함께 검토한다.
